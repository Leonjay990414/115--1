## 🌟 系統亮點與五大規格區塊實現總覽

### 第一區塊：會員註冊與資安防護矩陣
- **不強制綁定 Google 帳號**：降低學生與校外訪客使用門檻，結帳前強制填寫 6 大核心必填欄位（缺一不可）：
  1. `學號 (Primary Key)`：系統防偽、訂單追蹤與取貨核對主鍵。
  2. `班級`：所屬班級（如：資三1、美三1、普三1 等）。
  3. `座號`：01 ~ 60 號。
  4. `學生真實姓名`。
  5. `性別`。
  6. `聯絡電話`：09xxxxxxxx 格式嚴格正則校驗。
- **隱形閘道 (Hidden Gateway)**：
  - 前端商城首頁（`index.html`）**絕對禁止放置任何後台登入連結**。
  - 後台配置於獨立且隱密的專屬網址：[`admin.html`](./admin.html)。
- **15 人獨立帳號與 RBAC 權限矩陣**：全團隊成員依職責配置獨立帳密，介面自動進行權限隔離與個資脫敏遮蔽。
- **14 天個資銷毀承諾**：
  - 全程採用 HTTPS 加密傳輸。
  - 內建「活動結案 14 天後到期倒數計時器」，並提供總召/核心開發專屬「一鍵物理銷毀 (Wipe) 資料庫」指令，徹底銷毀所有學號、姓名、電話及訂單。

### 第二區塊：國際級 UI/UX 前端介面規範 (2026 設計大師課美學體系)
- **2026 全球代表色與淺色系美學體系 (Light Warm Luxury)**：
  - **Pantone 2026 年度代表色「雲舞白 (Cloud Dancer)」**：以柔和暖霞白取代刺眼冷死白，撫平資訊超載焦慮。
  - **WGSN 2026 年度代表色「變革藍綠色 (Transformative Teal)」**：作為品牌識別核心，象徵理性與生命力平衡。
  - **暖沙棕 (Warm Sand) & 鼠尾草綠 (Sage Green)**：提供大地與草本療癒感。
- **刻意的不完美 (Imperfect by Design)**：
  - 手繪紀念鋼印標籤、拍立得生活切片邊框，打破 AI 模板化複製的死板，保留手工人味。
- **度量衡革新 (Resolution Velocity)**：
  - 核心指標由「停留時間」轉向「意圖解決速度」，前端 0.1 秒即時解析度判定與極速雙重確認。
- **絕對單行鎖定 (Single-Line Lock)**：
  - 商品標題、客製要求備註等嚴格套用 CSS 截斷語法：`white-space: nowrap !important; text-overflow: ellipsis !important; overflow: hidden !important;`。
  - 搭配水平滑動容器，絕不允許文字折行破壞旗艦版面。
- **零死當與防呆交互設計 (Zero Dead-End)**：
  - 狀態反饋：點擊「加入購物車」、「上傳圖檔」、「送出訂單」立即鎖定並顯示旋轉圈圈載入動畫（Spinner Loading），防止重複點擊。
  - 功能隱藏原則：所有按鈕皆具備 100% 響應邏輯，不留無作用的假按鈕。
  - 頂級 Toast 通知：從螢幕上方動態滑入醒目紅/綠/金提示橫幅。
- **旗艦電商標準模組**：
  - 導覽麵包屑（首頁 > 62週年校慶限定 > 客製商品專區）。
  - 購物車懸浮側邊欄抽屜（點擊即滑出，不需重新整理或跳轉頁面）。
  - 2026 設計趨勢互動導覽與隨堂互動小測驗。
  - 頁尾完整標示購物須知、客製不退費規範與資安宣告。

### 第三區塊：購物流程與核心品項獨立拆單邏輯
- **商品詳情與 1080P 圖檔上傳**：
  - 5 大商品（陶瓷馬克杯、瞬吸杯墊、金屬胸章、皮革悠遊卡套、客製護照套）明確標示尺寸與材質規格。
  - 下單強制附上圖檔，限制 PNG/JPG/WEBP 格式；前端即時計算原圖寬高解析度，達標（寬高 ≥ 1080px）即時顯示綠色合格標章，畫質不足立即顯示黃色警告。
- **結帳雙重確認機制 (Double Confirmation)**：
  - 送出前彈出確認視窗，核對：(a) 選購商品 (b) 單價與總價 (c) 聯絡電話 (d) 客製要求備註 (e) 班級與座號姓名。
- **核心智慧拆單演算法 (Split Order Logic)**：
  - 購物車中若有不同商品（如：1 個馬克杯 + 1 個胸章），送出後自動拆分為 2 張獨立工單（如：`ZG2026-XXXX-MUG`、`ZG2026-XXXX-BDG`）並配置專屬流水號，方便產線與美術組個別審核與熱轉印。
  - 同商品多件（如：3 個馬克杯）則維持單一張工單，數量欄位標示為 3。

### 第四區塊：後台審核 QC 與自動化報表匯出
- **美術視覺組強制圖檔審查**：
  - 新單預設標示為「待審核」，美術組可點擊圖檔開啟原圖全螢幕檢視器與在新分頁檢視原圖。
  - 審核通過：狀態變更為「審核通過」，啟動「3 天送單倒數」，解鎖 A4 雙聯單列印。
  - 退件：填寫具體退件原因；**若顧客至第 4 天仍未上網更新圖檔，系統自動列入清單，由外送組一鍵印出實體「圖檔退件通知單」親自送至該班級提醒！**
- **自動排版 A4 雙聯確認單**：
  - 零人工編輯，審核通過訂單一鍵套印標準 A4 雙聯單（上聯顧客憑證，下聯財務存根）。
  - 自動帶入訂單號、學號、班級座號、姓名、商品、數量、總額、備註與條碼。
  - 中間精準切割中折撕線（`✂ - - - 請沿虛線撕開 - - - ✂`），保留財務收款與顧客核對空白簽名欄供現場簽署。
- **Excel 總表匯出（嵌入 `=HYPERLINK` 公式）**：
  - 整合 SheetJS，一鍵下載 `.xlsx` 訂單總表。
  - 「圖檔連結」欄位寫入 `=HYPERLINK("...", "點此檢視原圖")` 函數，機台作業員點擊 Excel 儲存格即可直連瀏覽器開啟原圖！

### 第五區塊：部署架構與未來擴展 (DevOps & PWA)
- **GitHub Pages 與 GitHub Actions 自動化部署**：
  - 提供 `.github/workflows/deploy.yml`，推送程式碼自動驗證並推播至 `gh-pages` 分支。
- **PWA (Progressive Web App) 架構**：
  - 具備 `manifest.json` 與 `sw.js` (Service Worker)。
  - 手機瀏覽器開啟可直接「加到主畫面」，轉化為具備專屬 App 圖示與全螢幕體驗的原生 App。

## 🚀 本地啟動與測試指南

本專案採用純靜態高相容性技術架構，無依賴任何外部編譯步驟，即可於瀏覽器極速啟動：

```bash
# 使用 Python 內建輕量 HTTP 伺服器啟動 (支援 Service Worker 與 PWA)
python -m http.server 8080
```

- **顧客前端商城**：`http://localhost:8080/index.html`
- **後台隱密管理閘道**：`http://localhost:8080/admin.html`

## 🖨️ A4 雙聯確認單列印規格說明

1. 在後台切換至【財務對帳與 A4 雙聯單】頁籤。
2. 點擊「🖨️ 批次套印 A4 雙聯確認單」或特定訂單的「🖨️ 印雙聯單」。
3. 系統自動套用 `css/print.css` 規則：
   - 頁面強制鎖定為標準 **A4 直向 (A4 Portrait)**。
   - 上半部為【上聯：顧客核對取貨憑證】。
   - 下半部為【下聯：大會財務暨產線存根】。
   - 中間具備剪刀撕斷標線與防偽流水號，並保留親筆簽名空白欄。
